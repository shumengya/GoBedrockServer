# 放置禁止：自身脚底列

状态：**暂时修好**（2026-08-23）  
协议：MCPE 1.1.x / protocol 113

## 现象

对着自己脚下堆柱子时，方块会放进身体里。第三人称能看到腿卡在柱顶石头中。

典型日志（修之前）：

```
Steve 放置拒绝: (1,18,0) 占用身体 pos=(1.30,18.87,0.50)
Steve 放置拒绝: (1,18,0) 占用身体 pos=(1.30,18.62,0.50)
Steve 放置方块 id=1 于 (1,18,0)    ← 同一格随后被放行
```

客户端会先本地预测放置，把人顶高；服务端若跟着更新脚坐标，就会把原脚底格当成「脚下可放」。

## 试过但放弃的做法

AABB 相交、拒绝格子 TTL、`MovePlayer MODE_RESET` 拉回、忽略踩空气上移。

1.1 客户端预测仍会先把方块放上去；服务端再拉人/回滚，容易引出更多错位，且拦不住「顶高后再放同一格」。

## 当前规则

右键 `UseItem` 算出目标格 `(nx,ny,nz)` 后，用 `MovePlayer` 跟踪的脚坐标做格点比较：

同一列（`floor(X)`、`floor(Z)` 相同）禁这三格：

| 格 | 含义 |
|----|------|
| `floor(Y) - 1` | 往下一格 |
| `floor(Y)` | 脚底格 |
| `floor(Y) + 1` | 往上一格（头） |

旁边的列、再高一格、再低一格仍可放。

拒绝时：不 `SetBlock`，只广播该格空气 `UpdateBlock`（清客户端预测），**不强拉玩家坐标**。

## 复测

1. 超平坦上对自己脚下连点放置。
2. 人不应卡进石头；日志为 `放置拒绝: ... 是脚底/头/下一格`。
3. 在相邻列正常搭方块应成功。

## 已知限制

- 客户端仍可能闪一帧预测方块，随后被空气包清掉。
- 只按脚坐标所在列的三格禁放，没有完整碰撞箱；斜着跨格踩边仍可能漏。
- 若以后要更严，优先扩「同一列的 Y 范围」，不要再上橡皮筋拉回。
