# 掉落物：丢弃抽搐与捡起失败

状态：**暂时修好**（2026-08-24）  
协议：MCPE 1.1.x / protocol 113  
对照：PocketMine `Player::dropItem` / `Item::onUpdate` / `Player::checkNearEntities`

功能总述与 `/summon` 实体表见 [生物实体.md](生物实体.md)。

## 现象

1. **丢出位置不对**：物品从玩家正上方、身前约 2 格的空中「蹦」出来，不是从身上抛出。
2. **捡起范围过大**：离得较远也会吸进背包。
3. **落地抽搐**：掉落物在空中或刚落地时反复跳动。
4. **收缩捡起范围后捡不起来**：站在物品上也不进背包。

## 原因

### 丢出点被改偏

PocketMine 是 `dropItem($this->add(0, 1.3, 0), $item, 朝向×0.4, 40)`：在**胸口/手部高度**生成，靠初速度飞出去。

中间一版为了「不做重力也不被立刻吸回」，把生成点前移了 2 格，初速度还多加了向上的 `0.1`。没有落地物理时，物品就停在头顶前方。

### 捡起判定两头都不合适

| 版本 | 做法 | 结果 |
|------|------|------|
| 过宽 | 脚坐标为球心、半径 1.8 | 离很远也会捡 |
| 过窄 | 按脚底 AABB 扩 `(1, 0.5, 1)` | 1.1 客户端有时上报**眼睛高度**，地上的物品对不上，完全捡不到 |

### 抽搐是服务端和客户端抢轨迹

`AddItemEntity` 带初速度后，1.1 客户端会自己播抛物线。若服务端再：

- 落地 `motionY *= -0.5`（未先把 `motionY` 置 0，实际会弹）
- 每 5 tick 或落地瞬间发 `MoveEntity` 把物品拽到服务端坐标

客户端预测和服务端瞬移就会对着打，看起来像抽搐。

PocketMine `Entity::move()` 碰到地面会把 `motionY` 置 0，后面的 `× -0.5` 实际是 0；停下时还会 `setImmobile(true)`，避免客户端继续自己动。

## 当前规则

### 丢出

客户端 `DropItem`（0x2e）→ 服务端扣背包（创造不扣，旁观忽略）→ `AddItemEntity`（0x0f）：

- 生成点：玩家坐标 **`+ (0, 1.3, 0)`**
- 初速度：朝向向量 × **0.4**（不再加向上的 0.1）
- 服务端每 tick 重力 0.04、阻力 0.02；碰到实心方块后**速度清零**，不弹跳
- **飞行中不发 `MoveEntity`**，抛物线交给客户端
- 约 **20 tick** 后发 `SetEntityMotion(0)` + metadata `DATA_FLAG_IMMOBILE`，停住余抖，**不改位置**

创造模式丢出后回写背包，热键栏不会被掏空。生存若 `RemoveItem` 失败，假定客户端已用 `ContainerSetSlot` 扣过，仍生成掉落物。

### 捡起

- 丢出后 **40 tick（2 秒）** 内不能捡
- 水平约 **1.25 格**；垂直兼容脚底 / 眼睛两种 Y
- 背包能放下整叠时：`TakeItemEntity` + `RemoveEntity`，物品进背包
- 创造模式只收掉实体，不往背包加（避免和「创造不扣」叠成复制）
- 约 **2000 tick（100 秒）** 后消失
- 新玩家出生会补发地上已有的掉落物

`/summon item` 仍然不行，掉落物必须带物品数据。

## 复测

1. 生存按 Q：物品从角色身上抛出并落地，不要从头顶前方空中出现，落地后不要抽搐。
2. 等约 2 秒，走近约一格内应能捡回；站在两三格外不应吸走。
3. 创造丢出：地上有掉落物，热键栏数量不变；捡起后地上消失、背包不增加一份。
4. 旁观不能丢、不能捡。
5. 第三人称看抛物线应平滑，落地后停住。
