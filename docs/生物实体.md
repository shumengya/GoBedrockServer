# 生物实体

状态：**已落地（召唤无 AI；掉落物可丢可捡）**  
协议：MCPE 1.1.x / protocol 113  
对照：PocketMine `Entity::init()` / `SummonCommand`

实现位置：

- `internal/entity/`：类型注册表（一类型一文件，由 `scripts/gen_pm_entities` 生成）
- `internal/command/summon.go`：`/summon`
- `internal/server/server.go`：内存实体表、广播 `AddEntity` / `AddItemEntity`、丢弃与捡起
- `internal/protocol/packets/add_entity.go`、`add_item_entity.go`、`drop_item.go`、`set_entity_motion.go`

用指令或刷怪蛋召唤的生物目前站在原地；正常保存后重启，会在原世界、原位置重新出现，保留名字和朝向。掉落物有重力、捡起延迟和超时消失机制。存档格式见[持久化存储](持久化存储.md#entitiesjson)，掉落物行为见[掉落物丢弃与捡起](掉落物丢弃与捡起.md)。

## 掉落物

玩家按 Q / 从背包丢出物品时，客户端发送 `DropItem`（0x2e）。服务端从背包扣减（创造模式不扣），对齐 PocketMine `Player::dropItem`：

- 生成点：玩家脚底坐标 **`+ (0, 1.3, 0)`**（胸口/手部高度，不是身前高空）
- 初速度：朝向向量 × **0.4**
- 每 tick 重力 **0.04**、阻力 **0.02**，碰到实心方块后速度清零落地（不弹跳）
- 飞行中不发 `MoveEntity`（避免位置瞬移和客户端抛物线打架）。约 20 tick 后发 `SetEntityMotion(0)` + immobile，停住客户端余抖

捡起：水平约 **1.25 格**，垂直留出脚底/眼睛坐标差异：

- 丢出后 **40 tick（2 秒）** 内不能捡（避免刚丢立刻吸回）
- 走进掉落物且背包能放下整叠时，广播 `TakeItemEntity` + `RemoveEntity`，物品进背包
- 创造模式捡起只收掉实体，不往背包里加（避免和「创造不扣物品」叠成复制）
- 约 **2000 tick（100 秒）** 后自动消失

新玩家出生时会看到地上已有的掉落物。

现象、原因和修法（生成点、抽搐、捡起范围）见 [掉落物丢弃与捡起.md](掉落物丢弃与捡起.md)。

## `/summon`

```text
/summon <实体名|id> [x y z]
```

- 实体：注册表名称（不区分大小写，可带 `minecraft:` 前缀）或 PocketMine `NETWORK_ID` 数字
- 坐标：省略则在执行者当前位置生成；支持 `~` / `~1` 相对坐标（Y 用 `~` 时限制在 0–128）
- 不支持 NBT

示例：

```text
/summon zombie
/summon minecraft:cow
/summon 32
/summon zombie ~ ~1 ~
/summon creeper 10 64 20
```

名称与数字 ID 等价，例如 `/summon zombie` 与 `/summon 32` 都是僵尸。

## 本轮不做

- AI、寻路、攻击、燃烧（召唤出的生物仍不移动）
- 伤害、死亡、生物掉落、骑乘、拴绳
- 破坏方块掉落
- 实体存档、区块可视距离裁剪（当前全图广播）
